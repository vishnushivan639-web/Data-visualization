Data visualization week 1

## 📌 Project Overview

This project was completed as part of my Big Data Analytics Week 4 assignment. In this project, I worked with the Sample Superstore Dataset using Python. The main objective of this project is to perform basic data analysis and visualization. I explored the dataset, converted date columns, created a new feature called Delivery Days, analyzed category-wise sales, and generated charts to understand the data better.

---

## 🎯 Objectives

- Load the Sample Superstore dataset.
- Explore the dataset information.
- Convert Order Date and Ship Date into DateTime format.
- Create a new column called Delivery Days.
- Check for missing values.
- Analyze sales by category.
- Visualize the data using charts.

---

## 🛠️ Technologies Used

- Python
- Pandas

- Google Colab

## 📂 Dataset

Dataset Name: **Sample Superstore Dataset**

## 📋 Project Steps

### Step 1
Imported the required Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

### Step 2
Loaded the Sample Superstore dataset into Python.

### Step 3
Displayed the first few records of the dataset using the `head()` function.

### Step 4
Checked the dataset information using `info()` and viewed summary statistics using `describe()`.

### Step 5
Converted the **Order Date** and **Ship Date** columns into DateTime format.

### Step 6
Created a new column called **Delivery Days** by calculating the difference between Ship Date and Order Date.

### Step 7
Checked the dataset for missing values using the `isnull()` function.

### Step 8
Grouped the dataset by Category and calculated the total sales for each category.

### Step 9
Created a **Bar Chart** to display category-wise sales.

### Step 10
Created a **Histogram** to understand the distribution of sales values.
